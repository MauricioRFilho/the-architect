# 🏗️ The Architect - Projeto: Handover de Elite

Este documento serve como guia de sincronização para o próximo agente ou para a continuação do desenvolvimento no diretório oficial.

## 🎯 Objetivo e Visão
Criar uma landing page institucional de ultra-performance (Lighthouse 100/100) com estética minimalista e brutalista.

---

## 📍 Estado Atual (Checkpoint: 2026-03-05)

### 1. Framework & Configuração
- **Astro 4.0** (Zero JS default).
- **Tailwind CSS** (Design system Noir/Platinum).
- **Framer Motion** (Instalado e pronto para uso).
- **GEMINI.md**: Protocolos de Agente + **PowerShell Mandatório** ativos.

### 2. Componentes Implementados
- **[Navbar.astro]**: Menu fixo com desfoque e tipografia minimalista.
- **[Hero.astro]**: Impacto visual inicial com animações de "reveal".
- **[Showcase/WorkItem]**: Grid de projetos com animações de hover dinâmicas.
- **[Manifesto]**: Seção conceitual de rodapé.

---

## ⚠️ REGRAS DE OURO (P0)
- **Terminal**: No Windows, use **SEMPRE o PowerShell** (`powershell.exe`).
- **Performance**: Manter o "zero JS" no carregamento inicial.
- **Estética**: Respeitar a tipografia `Outfit` e o contraste agressivo.
