# The Architect - Rules

Este repositório segue os padrões do Antigravity Kit.

## Padrões de Qualidade

1. **Clean Code:** Siga as skills de `@clean-code`.
2. **Terminal (CRÍTICO):** SEMPRE utilize **PowerShell** para comandos CLI (ex: `powershell.exe -Command "..."`). No Windows, o PowerShell oferece melhor tratamento de caminhos e scripts de automação.
3. **Performance:** Meta constante Lighthouse 100/100.
